 ### 3️⃣ Быстрый чек‑лист                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                             
 1. Установлен ли SearXNG?                                                                                                                                                                                                                                   
   ```bash                                                                                                                                                                                                                                                   
     pip show searxng   # если pip‑установлен                                                                                                                                                                                                                
     docker ps | grep searxng  # если через Docker                                                                                                                                                                                                           
   ```                                                                                                                                                                                                                                                       
 2. Запущен ли сервис?                                                                                                                                                                                                                                       
   ```bash                                                                                                                                                                                                                                                   
     systemctl status searxng   # если сервисный юнит                                                                                                                                                                                                        
   ```                                                                                                                                                                                                                                                       
 3. Найдите порт в конфиге searx.conf (http_port = 8888 по умолчанию).                                                                                                                                                                                       
 4. Проверьте DNS (если у вас доменное имя).                                                                                                                                                                                                                 
   ```bash                                                                                                                                                                                                                                                   
     dig +short searx.example.com                                                                                                                                                                                                                            
   ```                                                                                                                                                                                                                                                       
 5. Проверьте соединение через curl/wget и убедитесь, что получаете JSON/HTML.
